# 📊 Excel Interactive Dashboard

## 📌 About the Project

This project is an interactive Excel dashboard created to analyze and visualize data efficiently. It focuses on converting raw data into meaningful insights using Excel tools and techniques. Users can explore data dynamically through filters and slicers.

---

## 🛠️ Tools & Technologies

* Microsoft Excel
* Power Query
* Pivot Tables & Pivot Charts
* Slicers

---

## ✨ Features

* Interactive dashboard with slicers
* Multiple charts connected to one filter
* Cleaned and transformed data
* Proper Month & Day sorting
* User-friendly and protected sheet

---

## 🔍 What I Did

* Cleaned and transformed raw data using Power Query
* Extracted Month and Day from date column
* Created Pivot Tables and Charts
* Connected slicers to multiple visuals
* Fixed sorting issues for Month and Day
* Built a fully interactive dashboard

---

## 📊 What I Measured

* Overall performance (e.g., total values)
* Monthly trends
* Category-wise comparison
* Day-wise patterns
* Segment-based insights
